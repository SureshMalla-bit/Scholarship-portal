# Scholarship-portal
This is a website to check the statuses of all those scholarships (whether they are approved or rejected) and the list of available scholarships as well.

## Structure
| Folder | What | Details |
|---|---|---|
| [`backend/`](backend/) | Spring Boot 3 REST API (Java 17, JPA, MySQL / PostgreSQL, login tokens) | [backend/README.md](backend/README.md) |
| [`frontend/`](frontend/) | React (Vite) app for students and admins | [frontend/README.md](frontend/README.md) |
| `Dockerfile` | Builds both into one service: the website and the API share one address | |
| `render.yaml` | Render Blueprint: creates the database and the web service in one click | |

## Go live (Render, about 10 minutes, free)
1. Sign in at https://render.com with GitHub and allow access to this repository.
2. Render dashboard > **New** > **Blueprint** > pick `Scholarship-portal`. Render reads `render.yaml`.
3. It asks for **ADMIN_PASSWORD**: type a strong password. This becomes the admin login (`admin@scholarship.com`).
4. Click **Apply**. Render creates the PostgreSQL database and the web service, then builds (first build takes 5-10 minutes).
5. Open `https://scholarship-portal.onrender.com` (the exact address is shown on the service page).
   Log in as the admin, or register a student account.

Every push to the main branch redeploys automatically. `JWT_SECRET` (signs login tokens) is generated by Render.

Things to know about the free plan:
- The service sleeps after 15 minutes without visitors; the next visit takes about a minute to wake it.
- Render's free PostgreSQL database expires 30 days after it is created. Before then, upgrade the database to a paid plan in
  Render, or use a free database elsewhere (for example Neon or Supabase): set `DB_URL` on the web service to
  `jdbc:postgresql://HOST:5432/DBNAME?sslmode=require` along with `DB_USERNAME` and `DB_PASSWORD`. `DB_URL` takes priority.
- Custom domain: service page > **Settings** > **Custom Domains**.

The admin password is only used the first time the server starts (when it creates the admin account).
To change it later, log in and use the database, or delete the admin row so it is recreated on the next start.

## Run locally
1. Backend: start MySQL, then in `backend/` run `./mvnw spring-boot:run` (Windows: `.\mvnw.cmd spring-boot:run`). API at http://localhost:8080/api
2. Frontend: in `frontend/` run `npm install` then `npm run dev`. App at http://localhost:5173

Local admin login: `admin@scholarship.com` / `admin123`.

## Other ways to deploy
The website can also be hosted separately (Vercel or Netlify, root directory `frontend`, env `VITE_API_URL=https://YOUR-API/api`)
with the API alone on Render (root directory `backend`, which has its own `Dockerfile`). Then set `FRONTEND_URL` on the API
to the website's address so the browser is allowed to call it.

## CI
- `docker.yml` builds the production image, starts it with PostgreSQL and runs the API tests (every push).
- `backend.yml` builds the API and runs `backend/ci/api-test.sh` (when `backend/` changes).
- `frontend.yml` installs and builds the React app (when `frontend/` changes).
